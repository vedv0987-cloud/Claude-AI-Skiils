    Quick Reference

    Everything you need to get started with Claude AI Skills

    Getting Started

    Install Claude Code CLI and configure your environment. Set up API keys and permissions for your team.

    npm install -g @anthropic-ai/claude-code

    Skill Configuration

    Configure skills in settings.json. Set up hooks, permissions, and environment variables.

    /update-config

    Team Setup

    Share skills across your team with shared configs. Use CLAUDE.md for project-level settings.

    claude --project-config ./CLAUDE.md

    API Integration

    Build custom skills using the Claude API and Anthropic SDK for specialized team workflows.

    /claude-api
